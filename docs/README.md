# Документация проекта

## Структура документации

```
docs/
├── README.md (этот файл)
├── api.md (API документация)
├── deployment.md (инструкции по развертыванию)
├── architecture.md (описание архитектуры, паттернов, обоснование технологий)
└── diagrams/
    ├── README.md (инструкции по диаграммам)
    ├── architecture-overview.md (основные компоненты)
    ├── microservices-interaction.md (взаимодействие)
    ├── api-contracts.md (API контракты)
    ├── database-schema.md (ER-диаграмма)
    └── deployment.md (инфраструктура)
```

## Диаграммы

Все диаграммы архитектуры находятся в папке `diagrams/` и созданы в формате Mermaid.

См. [diagrams/README.md](./diagrams/README.md) для инструкций по визуализации и экспорту.

## Для пояснительной записки

Используйте диаграммы из папки `diagrams/`:

1. Откройте нужный файл
2. Скопируйте Mermaid код
3. Вставьте в [Mermaid Live Editor](https://mermaid.live/)
4. Экспортируйте в PNG
5. Вставьте в Word документ
